<h1 align="center">🎬 GESTURE & VOICE CONTROLLED VIDEO PLAYER</h1>

<p align="center">
  <b>Touchless Media Control. Real-Time. Accessible.</b><br>
  Control VLC Media Player using <b>hand gestures</b> 🖐️ and <b>voice commands</b> 🎤 – a project blending <b>AI, Computer Vision, and NLP</b>.
</p>

<hr>

<h2>🌟 WHAT MAKES IT SPECIAL?</h2>
<ul>
  <li>✨ <b>No Mouse, No Keyboard</b> – Control videos using just your hand</li>
  <li>✨ <b>Voice-Driven Commands</b> – Say <i>Play</i>, <i>Pause</i>, <i>Forward</i>, <i>Volume Up</i>, and it listens</li>
  <li>✨ <b>Designed for Accessibility</b> – Aimed at helping people with physical limitations</li>
  <li>✨ <b>Real-Time Feedback</b> – Powered by OpenCV for lightning-fast gesture tracking</li>
</ul>

<h2>⚙️ HOW TO SET IT UP?</h2>

<h3>1️⃣ Clone the Project</h3>
<pre><code>git clone https://github.com/&lt;your-username&gt;/GestureVoiceVideoPlayer.git
cd GestureVoiceVideoPlayer
</code></pre>

<h3>2️⃣ Install Dependencies</h3>
<pre><code>pip install -r requirements.txt
</code></pre>

<h3>3️⃣ Run Gesture Mode</h3>
<pre><code>python gesture.py
</code></pre>
<ul>
  <li>Place your hand in the rectangle</li>
  <li>Press <b>‘a’</b> to calibrate skin tone</li>
  <li>Swipe <b>left/right/up/down</b> for playback & volume</li>
</ul>

<h3>4️⃣ Run Voice Mode</h3>
<pre><code>python voice.py
</code></pre>
<p>Say commands:</p>
<ul>
  <li><b>Play / Pause</b></li>
  <li><b>Increase / Decrease Volume</b></li>
  <li><b>Move Forward / Backward</b></li>
</ul>
